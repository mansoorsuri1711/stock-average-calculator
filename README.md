# Stock Average Calculator

Free stock average calculator at [stockaveragecalc.com](https://stockaveragecalc.com) — weighted average share price, cost basis, break-even, and unrealized P/L.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
